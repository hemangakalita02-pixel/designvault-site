## ⚡ How to Enable GitHub Pages (1-Click)

1. Go to repository: **Settings** &rarr; **Pages** (under Code and automation).
2. Under **Build and deployment** &rarr; **Source**: Select **Deploy from a branch**.
3. Under **Branch**: Select `main` and folder `/ (root)`.
4. Click **Save**!
5. In 30 seconds, your site is live globally at:
   `https://hemangakalita02-pixel.github.io/designvault-site/`
